# Mission Commerce

Jeu de simulation en équipes pour préparer **Les Défis du Commerce** (BTS MCO, BTS NDRC, TP REM · ESICIM Méru).

- **Version en ligne** (animateur + étudiants sur leurs PC) : `index.html`
- **Console hors ligne** (secours, un seul écran projeté) : `console-hors-ligne.html`

Les commerces, la ville de Lornac et les situations sont fictifs.
